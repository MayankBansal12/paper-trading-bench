# OHLCV fixtures

Deterministic **synthetic** daily OHLCV bars for the 50 tickers in
`UNIVERSE_V1` (`src/config/universe.ts`), covering 2024-01-02 through
2024-06-28 (129 trading days, Mon–Fri, no holiday calendar).

These are NOT real market data. Each ticker's series is generated by a
seeded PRNG (seed = FNV-1a hash of the ticker symbol) via
`scripts/generate-fixtures.ts`, so the same command always reproduces the
same bytes. This keeps the benchmark fully offline, deterministic, and
license-free for v0.

Regenerate with `pnpm run fixtures:generate`. To swap in real historical
data later, replace these files with same-shaped
`{date, open, high, low, close, volume}[]` arrays (ascending by date,
identical trading calendar across tickers) — `src/data/ohlcv.ts` doesn't
care where the bytes came from.

`FIXTURE_VERSION` (`src/data/ohlcv.ts`) folds a content hash of every file in
this directory into every run's canonical identity (`src/run/state.ts`), so
it updates automatically whenever these files' bytes change (regeneration, a
real-data swap, a date-range change) — there is nothing to bump by hand. A
run made against one fixture snapshot can never be silently conflated with a
run made against a different one.
